# فوميكس | FOMEX: صفحة هبوط

صفحة هبوط عربية (من اليمين إلى اليسار) لشركة **فوميكس لمواد العزل** في حلب، حرّيتان: الفلين المضغوط، وفلين XPS، والفلين الكربوني، ومواد الهوردي والإنشاء.

**الموقع المنشور:** https://ammarabokh.github.io/fomaxTest/

> **حالة المشروع:** نسخة أولية. وضع المراجعة ووسم «صورة توضيحية» متوقفان، لكن الصور الحالية ما زالت مولّدة بالذكاء الاصطناعي، ومواصفات المنتجات لم تُعتمد بعد. راجع [قائمة ما قبل النشر](#قائمة-ما-قبل-النشر).

---

## التشغيل

موقع ثابت بلا أدوات بناء ولا اعتماديات.

- **أسرع طريقة:** افتح `index.html` في المتصفح مباشرة.
- **عبر خادم محلي:**
  ```bash
  npx http-server -p 5510
  ```
  ثم افتح `http://localhost:5510`.

## بنية الملفات

```
index.html                 هيكل الصفحة
css/style.css              الألوان والتنسيق
js/main.js                 منطق الصفحة: الرسوم التوضيحية، المنتجات، النموذج
content/site-content.js    كل النصوص والمنتجات والإعدادات  ← ملف التعديل الرئيسي
images/
  hero/ products/ about/ uses/ brand/
  دليل-الصور.md            الصور المطلوبة وأسماؤها ومقاساتها
  برومبتات-الصور.md        برومبتات توليد الصور المؤقتة
```

## تعديل المحتوى

كل ما يحتاج فريق الشركة تعديله موجود في **`content/site-content.js`**، فلا داعي لفتح ملفات HTML أو CSS أو JS.

| ما تريد تعديله | الخانة في الملف |
|---|---|
| نصوص الأقسام | `texts` |
| الهاتف، العنوان، فيسبوك | `contact` |
| المنتجات: الوصف، السماكات، الأبعاد، الاستخدامات، المواصفات | `products[].desc` و `products[].fields` |
| حالة توفر المنتج | `products[].status`: `pending` أو `available` أو `unavailable` |
| إخفاء منتج | `products[].show: false` |
| صورة منتج | `products[].image`: مثل `'images/products/xps-board.webp'` |
| ربط استخدام بمنتج | `uses[].productIds`: مثل `['xps']` |
| الأسئلة الشائعة | `faq` |

**القواعد:**
- الحقل الفارغ `''` يظهر للزائر بعبارة «اسألنا عنها»، فلا حاجة لقيم مؤقتة.
- لا تضع أسعارًا أو مواصفات أو ضمانات قبل اعتمادها من الشركة.
- `{phone}` داخل أي نص يتحول تلقائيًا إلى رابط اتصال.

## الإعدادات

في `settings` داخل ملف المحتوى:

| الإعداد | الوظيفة |
|---|---|
| `draftMode` | حاليًا `false`. اجعله `true` لإظهار شريط المراجعة الذي يعدّ الحقول المنتظِرة، ووسوم «بانتظار الاعتماد» و«صورة مولّدة» |
| `generatedImages` | حاليًا `false`. اجعله `true` لوضع وسم «صورة توضيحية» على الصور |
| `formEndpoint` | رابط خدمة استقبال نموذج التسعيرة، مثل Formspree أو Google Apps Script |

### نموذج طلب التسعيرة
- **بدون `formEndpoint`:** لا يُرسَل أي شيء عبر الإنترنت. يتحقق النموذج من الحقول، ثم يجهّز نص الطلب ويعرض ثلاثة خيارات: رسالة نصية (SMS) إلى رقم الشركة، أو الاتصال، أو نسخ التفاصيل.
- **مع `formEndpoint`:** يُرسَل الطلب بصيغة JSON عبر POST، ويعرض رسالة نجاح أو خطأ.

## قائمة ما قبل النشر

- [ ] اعتماد وصف كل منتج ومواصفاته وحالة توفره
- [ ] تأكيد توفر مواد الهوردي والإنشاء للبيع، أو إخفاؤها
- [ ] اعتماد المنتج المناسب لكل استخدام (الأسطح، الجدران)
- [ ] استبدال الصور المولّدة بصور حقيقية (انظر `images/دليل-الصور.md`)
- [ ] صورة حقيقية لواجهة المقر وقوس عندان
- [ ] الشعار الرسمي وأيقونة المتصفح في `images/brand/`
- [ ] ربط النموذج بخدمة استقبال (`formEndpoint`)
- [ ] تعديل `og:image` في `index.html` إلى رابط كامل بعد اختيار النطاق
- [ ] إضافة خريطة فقط بعد تثبيت إحداثيات دقيقة للمقر
- [x] إيقاف وضع المراجعة (`draftMode: false`) ووسم الصور التوضيحية (`generatedImages: false`)
